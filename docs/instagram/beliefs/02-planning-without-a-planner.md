# Financial Planning Should Not Require a Financial Planner

## Caption

Financial planning should not require a financial planner for every ordinary question.

Can I afford this apartment? What happens if I take a career break? When could I retire? What changes if costs rise?

Those questions still need judgment. But the math should not be hidden behind jargon, upsells, or a black box.

nidhi is built around a simple belief: good tools should make you more independent, not more dependent.
