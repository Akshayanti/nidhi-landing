# Built for Everyone Tech Keeps Forgetting

## Caption

A finance tool that leaves people out is not neutral.

Money decisions are already stressful. The interface should not make them harder because someone is colour blind, uses a screen reader, processes information differently, or does not fit the default user imagined in a meeting.

Accessibility is not a bonus feature. It is part of whether the tool works.
