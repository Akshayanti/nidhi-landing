# Instagram Keywords & Hashtags Reference

Per-post hashtags and bracketed-keyword arrays for upcoming IG posts, sourced from the corresponding blog articles. Rules live in `PLAYBOOK.md` §3 (hashtags) and §6 (keywords block). This doc is the operational lookup — when a post is ready to draft, copy the hashtag line + keyword array from here into the IG post file's `## Caption` section.

**How these were tuned:**
- Every keyword passes the searchability test: "would a real person type this into IG search, in this language?" No filler.
- Per-post audience angle varies — each post in a series aims at a distinct sub-audience so IG's classifier doesn't anchor the account to one cluster.
- Hashtags and keywords don't duplicate each other — community-browse terms live in hashtags, search phrases + multilingual terms live in the keyword array.
- Multilingual coverage: EN base + targeted translations in languages where the native word is what people actually search (DE, FR, ES, IT, NL, PL, SV, NO, DA, CS). Cognates (`inflation`, `budget`, `euro`) aren't re-translated.
- Array size: 13–18 keywords per post (tight side of the 18–24 sweet spot documented in PLAYBOOK.md §6).
