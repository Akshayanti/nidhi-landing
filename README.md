# Nidhi

The website for [nidhi.today](https://nidhi.today/?utm_source=github&utm_campaign=readme).

## What's here

- **Blog** — personal finance articles organized by level: discovery, building, psychology, optimizing, and mastery.
- **Tools** — free financial calculators and tools.

## Local development

```bash
npm install
npm run dev          # start the dev server
npm run build        # production build
npm test             # run the test suite
npm run lint         # lint the project
```

Requires **Node.js >= 22**.
