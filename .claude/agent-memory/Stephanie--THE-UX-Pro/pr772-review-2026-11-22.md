Review of #772 on 2026-11-22 (branch feat/blog-list-plain-html, dev server 4420).

- **Pre-paint inline script vs module script.** LearnHome.astro's `is:inline` block swaps the start card to its "returning" version before paint, but only the module fills it. With the module blocked (or slow, or an old browser without modules), a returning reader sees "Continue where you left off", an empty h3 (`&nbsp;`), an empty bar and "Read lesson 1". The helper toggle is `visibility:hidden`, a 46px blank. Main's React island fell back to the new-reader card. A fix that worked when injected: on DOMContentLoaded (module scripts run before it), undo the swap unless `card.dataset.start` is set. Repro: abort `LearnHome.astro?astro&type=script` plus a stored progress array.
- **Search results at large text.** `.learn-result` is a flex row with a `flex: none` pill, and it stacks only below a px breakpoint (`width < 640px`). At 640px and 400% text, es/cs titles get 1 to 2 em, so they break letter by letter. At 1024-1280px and 400% they get 4 to 5 em. The CSS is older than #772, but this state had never been measured. A fix that worked when injected: `flex-wrap: wrap`, the title `flex: 1 1 12em`, the pill `flex: 0 1 auto`.
- **Audit gap:** `audit-text-size` reported only a "+3 spill" there. A squeezed box makes words "wider than their line", which the audit counts (forcedWords, 1480 against about 800) and does not fail. Live main has the same 56px title for q=debt on /es/blog/ at 640/400. A jump in forcedWords is a signal: look at it.
- **Phone regression on the year page (blocking).** Moving entries out of the notice lost the phone floor: the notice's selectors (`.changelog-summary`, `.changelog-details li` in global.css) don't match `.plog-*`, so entries went from 16px on main to 15/14px below 640px. When content moves to a new component, grep the floor list for its old classes.
- **Directory rows on phones (not blocking).** The reading time sits as close to the next title as to its own (7/6px at 375/100, 12/13 at 200%), because the link is 44px tall on its own.
- Dark: the notice's new "Permanent link" is teal on the changelog fill, 4.79:1, below the 5.6 exception (passes AA).
- **Dev is not live:** the dev server lists unpublished lessons (92 rows, against 71 in the build), so compare with main by a query that hits published lessons. Searching "money" finds nothing on main and here: it is a stop word in siteSearch.ts.
- **Verdict:** SIGN OFF at 73c8994 (first OBJECT at 3e59582, on the blank returning card and the year-page text size).
- **Recheck:** a phone font floor can create new splits at 320/400: rerun the text-size audit after proposing one, not only a scroll check. `.plog-details`' fixed 16px indent half-clips bullets from 300% (24px fixes it and the "1," split). For audit states that move focus, make the sticky header static in the preload to get true exit codes.
- **What was sound:** the helper's focus moves (legend, legend, result h3, restart), though at 375px and 400% the first legend is taller than the screen and starts above it (the same on main); the polite count after 600ms; "show all" focusing the first new result; `?q=` cleared while utm is kept; the anchors clear the sticky header (scroll-padding 61px plus scroll-margin).
- **Probe method:** the preload in the scratchpad imports puppeteer by its absolute path (lib/puppeteer/puppeteer.js), so scripts can stay outside the repo. Inject states with evaluateOnNewDocument; when you read overlaps, filter out the sticky header (nav-/logo-/lang-picker).

**How to apply:** for any pre-paint script, test the module-failed path in every stored state. For any flex row with a `flex: none` badge, test 300-400% at the breakpoint width. Related: [[pr752-review-2026-11-21]] (px breakpoints with rem text).
