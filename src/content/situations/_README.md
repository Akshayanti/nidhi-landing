# Situation pages

One file per situation page (`/how-to/situation/<slug>/`), with the schema in
`src/content.config.ts`. Files starting with an underscore, like this one, are
not pages.

The layer is built and switched off (`src/utils/guideLayers.ts`). It is
reviewed by the council at about 30 guides, and a situation is written only
where at least three live guides form a real cluster. Don't write one in
advance to fill the template.
